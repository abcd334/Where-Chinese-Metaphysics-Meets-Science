# Where Chinese Metaphysics Meets Science

目前專案是 **八字 Knowledge Engine**：建立機器可讀、可驗證、可追溯的八字知識庫。
當前工作是整理基礎元素及其白話說明，尚未進入命盤組合分析或個人命理解讀。

```text
基礎元素 → 關係／組合規則 → 命盤結構 → 命理解讀
目前重點   已有部分固定關係   尚未實作   尚未實作
```
